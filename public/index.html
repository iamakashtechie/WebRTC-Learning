Real-Time Communication Playground

Interactive testing dashboard for Long Polling, Server-Sent Events (SSE), and WebSockets

1. Long Polling

HTTP Hanging Request

Client requests /poll and the server keeps connection open until simulated data arrives (3s), then immediately re-polls.

2. Server-Sent Events

HTTP Stream (1-Way)

Client opens a persistent stream with EventSource('/events'). The server pushes real-time events every 2 seconds.

3. WebSockets

Full-Duplex (2-Way)

A bidirectional TCP connection over ws://localhost:3000. Client and server can push messages instantly.
